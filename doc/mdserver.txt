1. INTRODUCTION                                         *mdserver-introduction*

mdserver serves every markdown and HTML file of a project over HTTP: the files
as a tree on the left, the rendered document (or the HTML page, in a frame) on
the right. Links between documents, headings, code highlighting and mermaid
diagrams work, the page shows unsaved edits and follows the buffer you are in.

The server runs inside Neovim (|vim.uv|), so it stops when Neovim exits.

==============================================================================
2. INSTALLATION                                         *mdserver-installation*

Requires Neovim 0.10+ and `curl`. `git` is optional.

The browser libraries are pinned with their sha256 in `vendor.json` and
installed into `vendor/` by `build.lua`. lazy.nvim runs it on install and
update, `:Lazy build mdserver` runs it again. Otherwise use
|:MdServer| `install`, or `nvim -l build.lua` in the plugin directory.

$MDSERVER_CDN replaces the CDN (`https://cdn.jsdelivr.net/npm`).

`:checkhealth mdserver` verifies the installation.

==============================================================================
3. COMMANDS                                                 *mdserver-commands*

                                                                   *:MdServer*
:MdServer[!] [action][!] [arg]

The bang can follow the command or the action: `:MdServer! open` and
`:MdServer open!` are the same.

  (none)          Start, or open the browser on the current buffer.
  start [root]    Serve [root], default: project root of the current buffer
                  (see `root_markers`). Restarts when serving another root,
                  keeping the host of the running server.
  stop            Stop the server.
  toggle          Start or stop.
  open[!]         Open the browser on the current markdown buffer. Binds
                  the configured `host`, with ! 0.0.0.0 so the server is
                  reachable from another machine. Restarts the server on the
                  same root when the host changes.
  status          Show the URL, the root and the connected browser tabs.
  install[!]      Install the browser libraries. With ! download them again.

4. CONFIGURATION                                       *mdserver-configuration*

>lua
  require("mdserver").setup({
    host = "127.0.0.1",      -- "0.0.0.0" to reach it from another machine
    port = nil,              -- nil: stable port derived from the root (8100-9099)
    open_browser = true,     -- open the browser on start / :MdServer open
    browser = nil,           -- command to open the URL with, e.g. { "firefox" }
    follow = true,           -- the browser follows the markdown/HTML buffer
    root_markers = { ".git", ".hg", ".jj" },
    extensions = { "md", "markdown", "mdx" },
    html_extensions = { "html", "htm" }, -- pages shown in a frame, {} hides them
    skip_dirs = { "node_modules", "vendor", "target", "build", "dist" },
    debounce = 200,          -- ms between a buffer change and the refresh
  })
<
`skip_dirs` only applies outside of git repositories, inside them the file
list comes from `git ls-files` and honours `.gitignore`.

Binding another host than localhost makes every file of the project readable
from the network.

==============================================================================
5. LUA API                                                       *mdserver-api*

require("mdserver").setup({opts})                          *mdserver.setup()*
require("mdserver").start({root}, {opts})                  *mdserver.start()*
    {opts}: `{ host = string }` address to bind, default: the host of the
    running server, else the configured `host`
require("mdserver").stop({opts})                            *mdserver.stop()*
    {opts}: `{ silent = boolean }`
require("mdserver").toggle()                              *mdserver.toggle()*
require("mdserver").open({opts})                            *mdserver.open()*
    {opts}: `{ global = boolean }` bind to 0.0.0.0 instead of the
    configured `host`
require("mdserver").status()                              *mdserver.status()*
require("mdserver").install({opts})                      *mdserver.install()*
    {opts}: `{ force = boolean }`
require("mdserver").is_running()                      *mdserver.is_running()*
require("mdserver").url()                                    *mdserver.url()*
    URL of the running server, or nil.
require("mdserver").host()                                  *mdserver.host()*
    Address the running server is bound to, or nil.
require("mdserver").version                              *mdserver.version*
    Version string of the plugin, e.g. "1.0.0".

==============================================================================
6. BROWSER                                                   *mdserver-browser*

Keys in the page:

  /     Filter the file tree (Enter opens the first match, Esc clears).
  t     Toggle the file tree.
  e     Open the current document in Neovim.

Links to markdown and HTML files stay in the page, links to other project files
(images, sources) load them as they are, links to other sites open in a new tab.

                                                              *mdserver-html*
HTML files are listed in the tree and shown in a frame filling the right side,
loaded from `/_mdserver/raw/<path>`: their relative style sheets, scripts,
images and links work as when the file is opened on its own. A link to another
page inside the frame updates the URL, the tree and "Edit in Neovim". "Open"
shows the page alone in a new tab. The page reloads, keeping its scroll
position, as its buffer changes and when a file it loaded (css, js, ...) is
saved in Neovim. HTML pages ignored by git are not in the tree, links to them
still show them. Pages run with the server's origin, like the files it serves.

                                                              *mdserver-media*
Images resolve relative to the document, `/path` relative to the project root,
URLs load from the web. Video and audio files (mp4, webm, mov, ogv, mp3, m4a,
wav, ogg, flac) get a player when written with image syntax `![](demo.mp4)` or
when their URL is alone on a line. A YouTube or Vimeo URL alone on a line is
embedded. `<img>`, `<video>` and `<audio>` HTML is rendered as it is.
